# Wibify-Inspired Reconstruction Topology

Target: https://wibify.agency/

Legal/craft note: this project reconstructs the interaction model, section rhythm, and visual principles as an original implementation. It does not reuse Wibify's logo, brand assets, portfolio images, copy, or identity.

## Extracted Structure

1. Floating navigation over the page
   - Centered, bordered, dark translucent container
   - Logo/action/menu treatment

2. Cinematic hero
   - Full viewport, dark background
   - Large typography on the left
   - Sculptural/monolith visual on the right
   - Primary CTA, secondary CTA, proof metrics

3. Selected work
   - Numbered chapter header
   - Large heading
   - List rows with project name, discipline, year/outcome
   - Hover movement and image-preview feeling

4. Services
   - Four large disciplines
   - Repeated number/title/body/tags/action pattern
   - Stacked on mobile, grid on desktop

5. Process
   - Four ordered steps
   - Strategy, design, build, launch style flow
   - Each step has tags and a visual panel

6. Studio / founder
   - Image-like dark card, text about direct responsibility
   - Trust stats

7. Results / standards
   - Big score panels
   - Performance/SEO/quality targets

8. FAQ and references
   - Accordion-like questions
   - Open technical references

9. Footer
   - Large logo/wordmark feel
   - Contact CTA

## Interaction Models

- Header: static floating shell with hover states.
- Hero: time-driven entrance animation and ambient animated visual.
- Selected work: hover-driven row highlight.
- Services/process/results: scroll-reveal motion.
- FAQ: click-driven native details accordion.
- Page: Lenis smooth scroll, GSAP reveals, reduced-motion fallback.
