# Hero Specification

## Overview
- Target file: `src/App.tsx`
- Screenshot: `docs/design-references/wibify-desktop-reference.png`
- Interaction model: time-driven entrance + ambient CSS/GSAP motion

## Structure
- Floating header above hero
- Left copy block with chapter label, massive heading, paragraph, buttons, proof metrics
- Right visual block: generated monolith/rock-like stage made in CSS

## Visual Translation
- Dark background: near black with green/yellow accent
- Huge display type: uppercase/lowercase mixed, heavy weight, tight line-height
- Accent words are italic/green, inspired by reference typographic emphasis but original copy
- CTA buttons rectangular/premium with border and glow

## Responsive
- Desktop: two columns.
- Mobile: single column, centered visual moves below copy.
