# Project Rules

- Store all source files as UTF-8.
- Use real German characters in visible text: ä, ö, ü, Ä, Ö, Ü and ß.
- Never write German umlauts as `ae`, `oe`, `ue`, `Ae`, `Oe`, `Ue`, or broken sequences such as `Ã`, `Â`, or `â`.
- Before finishing text changes, scan the changed files for encoding errors and transliterations.
